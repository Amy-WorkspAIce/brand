# Banners

Full-bleed scenes on `night-000`: a banded sky, the sliced sun with the Orbit's ring around it, a skyline, the cyan horizon and a magenta grid floor. On the left sit the lockup, the tagline "The digital workspace of the future" and an `OPEN SOURCE  //  SELF-HOSTABLE` line. All text is outlined.

- `amy-workspaice-banner-github.svg`: 1280×320, for the top of the GitHub README or a docs site. `amy-workspaice-banner-github-2x.png` is the 2560×640 PNG twin.
- `amy-workspaice-banner-hero.svg`: 1920×640, for the website hero. `amy-workspaice-banner-hero-2x.png` is the 3840×1280 PNG twin.

Scale them to the container's width; never crop away the lockup. Don't place live text or buttons over the sun or the grid. If a hero needs a call to action, put it below the banner or over the plain sky on the left.
